# AdminTools

**AdminTools** is a powerful all-in-one administration and utility mod for **Minecraft Forge 1.20.1**.

It provides server administrators and players with useful commands, economy features, moderation tools, teleportation, rewards, shops, and many quality-of-life improvements.

---

## ✨ Features

### 🛡️ Administration
- Ban players
- Kick players
- Mute players
- Warn players
- Freeze players
- OP management
- Clear inventory
- Permission management

### 💰 Economy
- Balance system
- Bank system
- Deposit & Withdraw
- Player shops
- Lottery
- Tax system
- Jobs

### 🌍 Teleportation
- Home system
- Warp system
- Teleport requests
- Spawn commands

### 🎁 Utilities
- Daily rewards
- Helpful admin commands
- Inventory management
- Various server utilities

### ⚡ Other
- Mixins
- Configurable systems
- Modular design
- Forge 1.20.1 support

---

## 📦 Requirements

- Minecraft **1.20.1**
- Minecraft Forge **47.x**
- Java **17**

---

## 🚀 Installation

1. Install Minecraft Forge 1.20.1.
2. Download the latest AdminTools release.
3. Place the `.jar` file inside the `mods` folder.
4. Launch Minecraft using the Forge profile.

---

## 🛠️ Building

Clone the repository:

```bash
git clone https://github.com/yourusername/AdminTools.git
```

Build:

```bash
gradlew build
```

The compiled mod will be located in:

```
build/libs/
```
